# PORTA Operations Console

Admin console for the current PORTA V1 operations surface.

## Current Scope

- `System Health`
- `User Activity`
- `Trust Level`
- `Actions`

## Run

```bash
npm install
npm run dev
```

## Checks

```bash
npm run check
npm run build
```

## Environment

- `VITE_API_BASE_URL`
- `VITE_WS_BASE_URL`
